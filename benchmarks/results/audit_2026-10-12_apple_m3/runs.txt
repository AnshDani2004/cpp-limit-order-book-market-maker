# Audit benchmark rerun, 2026-10-12 (Apple M3 MacBook Air)

Purpose: independent rerun of the Stage 2 one million event benchmark for the resume audit.
Raw stdout of every run is below; per-run metrics (from each run's summary.csv) are in runs.csv.
Report what was measured: the machine was NOT idle. Other audit jobs were running in parallel
(1-minute load average 5.8 to 11.2 on 8 cores, recorded per run), so these numbers are a
loaded-machine lower bound, not a replacement for the idle-machine Stage 2 artifact.

## Build and test
cmake -S . -B build/audit_release -DCMAKE_BUILD_TYPE=Release
cmake --build build/audit_release --config Release -j 8
ctest --test-dir build/audit_release --output-on-failure
Build: no compiler warnings. Tests: 100% tests passed out of 69
Compile flags (compile_commands.json, benchmark and lob_core): -O3 -DNDEBUG -std=c++20 -arch arm64 -Wall -Wextra -Wpedantic

## What is timed
benchmarks/orderbook_benchmark.cpp: the full event stream is generated before timing (main, line 913),
20,000 warmup events are applied untimed, then each of the 1,000,000 measured events is wrapped in a
steady_clock::now() pair (replay_flow, lines 675-694). Throughput = measured events / wall time of
the whole measured loop (includes the two clock reads per event). Single thread, single process, no I/O.

## Timer granularity probe (timer_probe.cpp in this directory, clang++ -O3 -std=c++20)
back_to_back_now_ns: min=0 smallest_nonzero=41 p50=0 p99=42
mean_cost_per_now_call_ns=17.44
steady_clock_period_num_den=1/1000000000

## Commands
map book (default, the Stage 2 configuration), runs 1-15:
  ./build/audit_release/orderbook_benchmark --events 1000000 --warmup 20000 --seed 42 --output-dir <scratch>/map_runN
flat book, runs 1-3:
  ./build/audit_release/orderbook_benchmark --events 1000000 --warmup 20000 --seed 42 --book flat --min-price 99000 --max-price 101000 --output-dir <scratch>/flat_runN
Every run: 350,663 trades, 0 rejects (same deterministic stream as stage2_local).
